# Fragtpligtig Vægt — undervisningsforløb

Undervisningsforløb om fragtpligtig vægt (chargeable weight) til spedition og shipping.

Indhold:
- Hvad er fragtpligtig vægt, og hvornår bruges den
- 4-trins-modellen til prisberegning
- Omregningsfaktorer for luftfragt, vejgods og søfragt (LCL)
- 5 gennemregnede eksempler
- Interaktiv quiz med 7 spørgsmål

Siden er én selvstændig HTML-fil uden eksterne afhængigheder.

**Live:** https://mortensillesen.github.io/fragtpligtig-vaegt/
